# 🐾 Fan ID - Powered by FURIA

**Projeto desenvolvido para o desafio “Know Your Fan” da FURIA Esports.**  
O objetivo é identificar e engajar fãs da organização por meio de um app personalizado, com validações inteligentes, QR Code exclusivo e identidade visual inspirada na marca FURIA.

---

## 🎯 Objetivo

Criar um aplicativo Flutter que permita:
- Coletar informações pessoais de fãs
- Validar documentos via IA
- Vincular redes sociais
- Confirmar identidade através de links relacionados a eSports
- Gerar um Fan ID exclusivo com QR Code personalizado

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|------------|-----------|
| **Flutter** | Framework principal |
| **Dart** | Linguagem de programação |
| **GoRouter** | Navegação entre telas |
| **Provider** | Gerenciamento de estado |
| **OpenAI API (GPT-4o)** | Validação de documentos e links via IA |
| **QR Flutter** | Geração de QR Code com logo da FURIA |
| **Image Picker** | Upload de documento do usuário |
| **DotEnv** | Proteção de chave da API via `.env` |

---

## ✨ Funcionalidades

- [x] Cadastro de nome, endereço, CPF e interesses
- [x] Upload e "validação" de documentos
- [x] Validação de links com IA (GPT-4o)
- [x] Integração com redes sociais (Twitter, Discord, Twitch, Instagram)
- [x] Geração de QR Code com a logo da FURIA embutida
- [x] Tema escuro inspirado na identidade da FURIA
- [x] SplashScreen com logo animada
- [x] Animações suaves e transições modernas
- [x] App 100% responsivo, preparado para demonstração real

---

## 🧠 OpenAI na Prática

- **Validação de links:**  
  A IA interpreta se o conteúdo compartilhado está relacionado a e-sports ou à FURIA.

- **Simulação de validação de documento:**  
  Por limitações da API (visão), o app simula uma verificação bem-sucedida, simulando um fluxo realista.
